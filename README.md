# 🍵 Absürt Çay Demleme Protokolü

## Bu Nedir?

Bu, çay demlemenin **TEK DOĞRU**, bilimsel, kozmik ve tartışmasız protokolüdür. 
Diğer tüm çay demleme yöntemleri yanlıştır, yanlıştır, yanlıştır.

NASA, MIT, Çay Araştırma Enstitüsü (uyduruk) ve büyükanneler bu protokolü onaylamıştır. (hiçbiri onaylamadı)

## Özellikler

- Çayı gerçekten demler (simülasyon olarak)
- Her çalıştırmada farklı bir sonuç verir (rastgele)
- Köpük üretir (sanal)
- Dünya barışına katkıda bulunur (iddia)
- %100 Türkçe, %0 patates

## Kullanım

```bash
python cay_demle.py
```

Çayınız hazır olacak. (olmayacak ama öyle hissedeceksiniz)

## Uyarılar

- Bu kod çay içmez, siz içersiniz.
- Gerçek çay demlemek için su ve çay yaprağı gerekir. (sürpriz!)
- Aşırı kullanım durumunda bilgisayarınız çay demleme ritüeline girebilir.

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Protokol mükemmeldir. 
Değiştirmek küfür sayılır.
